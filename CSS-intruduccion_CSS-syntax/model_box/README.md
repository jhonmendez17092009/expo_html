En CSS, el término "modelo de caja" se utiliza al hablar de diseño y maquetación web.
El modelo de caja CSS es esencialmente una caja que envuelve cada elemento HTML.
Cada caja consta de cuatro partes: contenido, relleno, bordes y márgenes.
La siguiente imagen ilustra el modelo de caja CSS:

Contenido : el contenido del cuadro, donde aparecen texto e imágenes.
Relleno : crea un área alrededor del contenido. El relleno es transparente.
Borde : un borde que rodea el relleno y el contenido.
Margen : elimina un área fuera del borde. El margen es transparente.

El modelo de caja nos permite añadir un borde alrededor de los elementos y definir el espacio entre ellos.
